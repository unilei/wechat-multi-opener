# 兼容性说明

## 当前构建目标

| 项目 | 当前值 |
| --- | --- |
| 最低 macOS | 13.0 |
| 构建架构 | Universal：arm64 + x86_64 |
| 本地验证环境 | macOS 26.7，Apple Silicon |
| 本地验证微信 | 4.1.11，build 269136 |
| 签名 | ad-hoc，仅适合开源自用和本地测试 |

## 已验证

- Swift 源码可以分别编译 arm64 和 x86_64，并通过 `lipo` 合并。
- App 的 Info.plist、Bundle ID、代码签名和 `--selftest` 流程通过。
- 登录项注册/注销测试通过。
- 原版微信可以被 Bundle ID `com.tencent.xinWeChat` 精确识别。

## 尚未承诺

- 所有微信 4.1.x 版本；微信升级后需要重新验证。
- 多账号长期同时在线、消息通知、音视频、屏幕录制和所有系统权限。
- 副本一定保留登录状态或一定不需要重新扫码。
- Intel 真机上的完整运行回归。

## 建议的版本回归记录

每次发布前，在干净用户环境至少记录以下结果：

1. 创建 2 个副本并分别启动；
2. 每个副本独立扫码登录；
3. 发送和接收消息，检查系统通知；
4. 检查摄像头、麦克风、文件选择和屏幕共享等实际需要的权限；
5. 升级原版微信，执行“一键重建”，再次检查登录和通知；
6. 执行清理扫描，确认原版微信和原版数据未被列入范围。
