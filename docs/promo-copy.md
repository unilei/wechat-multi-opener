# 宣传文案

以下文案只描述已经实现或明确限制的能力，适合 GitHub 项目页、社交平台和开源社区发布。不要使用“官方原版功能一致”“安全无风险”“无需重新扫码”“支持所有最新版本”等无法保证的表述。

## 短版

开源的 macOS 微信多开助手：基于本机官方微信创建独立副本，支持 Intel/M 芯片，提供 GUI 创建、打开、版本检查、更新重建、环境体检和清理卸载。源码透明、无需远程控制，适合个人学习和自用。

首次使用副本可能需要独立扫码登录；微信升级后需要重新验证副本。项目不属于腾讯官方产品，账号和兼容性风险请自行评估。

## 长版

如果你需要在同一台 Mac 上运行多个微信实例，可以试试这个开源工具。

它不依赖第三方常驻软件，也不要求日常使用时打开终端：打开助手后即可创建和启动微信副本。项目支持 Intel 和 Apple Silicon，提供环境体检、版本过期提醒、一键重建、操作日志和安全范围有限的清理卸载。

这是一个透明的本地工具：不会上传微信数据，不包含 ToDesk 或远程控制逻辑，也没有账号托管功能。由于副本使用新的 Bundle ID 和本地 ad-hoc 签名，首次使用可能需要独立扫码，通知和系统权限也可能需要逐副本授权。微信版本兼容性请以项目 Release 的实际测试记录为准。

## 发布时应附带

- GitHub 仓库链接；
- 当前 Release 的微信 build 兼容记录；
- SHA-256 校验值；
- 使用风险和首次登录说明；
- “问题反馈请提供日志，不要上传聊天记录和容器数据”的提醒。
